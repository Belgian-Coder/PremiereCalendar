# v1.2.23 - Dependency refresh

## Changes

- Package updates: Npgsql 11.0.0 (was 10.0.3; the app uses none of the
  removed features: multiplexing, large-object APIs or the separate
  dependency-injection package), Serilog.AspNetCore 11.0.0 (was 10.0.0) and
  Magick.NET-Q8-AnyCPU 15.1.1 (was 15.1.0) with its bundled ImageMagick
  7.1.2-36 runtime. The upstream 15.1.0..15.1.1 diff does not touch
  configuration-file handling, so the app's own `policy.xml` still applies.
  The published third-party notices follow the new package's `Notice.txt`.
- The .NET 11 SDK (11.0.100) and ASP.NET Core runtime (11.0.0) images, the
  other NuGet packages and the test packages were already the newest stable
  releases.

## Local build, test and release harness

- The PostgreSQL image pinned in `compose.yaml` and `compose.dev.yaml` (used
  by the tests, the release restore check, the smoke test and local
  development) moves from 18.6 to 18.7, a minor release of the same major
  version. The NAS database container is not part of an app release and is
  not changed by it.
- Release scanner defaults: Trivy 0.76.2 (was 0.74.0) and Syft 1.57.2 (was
  1.51.0).
- Microsoft.Playwright.Xunit.v3 stays at 1.64.1: the prepared browser image
  ships the Playwright 1.64 browsers (chromium-1248), and 1.65 needs a new
  prepared image.
- The prepared browser image is now reproducible from the committed recipe
  `eng/browser-image/Dockerfile` (the official Playwright 1.64.1 "resolute"
  image plus the pinned .NET 11 SDK, both pinned by digest); the build
  command is in `docs/Testing.md`. The earlier locally prepared image had no
  recipe in the repository and was lost in a disk cleanup.

## Release boundary

The database schema stays at version 4, so an app-only rollback to 1.2.22 is
possible. Installed acceptance is recorded after the exact release passes its
gates and is verified on the NAS.
