# Generated assets

PremiereCalendar has no Node-based generated web bundle. Files under
`PremiereCalendar/wwwroot/` are shipped inputs and are fingerprinted by the
qualification report. The Docker build must produce and the smoke test must
serve `_framework/blazor.web.js`; this runtime-generated framework asset is not
committed.

NuGet `packages.lock.json` files are generated by the pinned SDK but are source
inputs and must be committed. Restore uses locked mode so dependency drift
fails instead of silently changing qualification.

The following are generated evidence and remain ignored: `bin/`, `obj/`,
`TestResults/`, `.dotnet/`, `artifacts/`, local Playwright state, packages,
SBOMs, scan reports, and screenshots outside `docs/images/readme/`.

README screenshots under `docs/images/readme/` are curated source assets. Only
replace them after a deliberate browser capture and visual review. Bootstrap
files under `wwwroot/lib/` are vendored source; changes require explicit
provenance and browser qualification.
